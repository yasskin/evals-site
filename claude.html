Higher-budget retry study

Fresh conversations for the 62 incomplete tasks, with larger limits: 32k tokens per response (from 10k), 150k per conversation (from 50k), 28 turns (from 14) and 48 tool calls (from 24).

Result: 54 completed, 53 with artifacts; four incomplete; four provider errors. This suggests sensitivity to the budget configuration, but several settings and fresh sampling changed together. Retry quality is ungraded and does not replace primary results.

Counterexamples: where Claude's work was stronger

Both judges favored Claude on 29 task pairs, versus 17 for GPT. Examples include a surveillance report that linked photographic evidence to each timeline entry and a warehouse SOP that covered grounding requirements GPT omitted. Most pairs remain unresolved, so this is not an overall quality ranking.

Dataset proposal: deliverable-first, budget-aware execution

  • Tasks: long-horizon professional workflows with references, multi-step research and file creation.
  • Trajectories: early creation of a minimally complete artifact, then iterative improvement.
  • Supervision: explicit budget accounting and prioritization of essential research and tool calls.
  • Acceptance tests: a requested deliverable exists, opens and satisfies core requirements before the run ends.
"The opportunity is converting more of Claude's work into delivered outcomes. These tasks show where planning and tool use consume the budget before the professional artifact exists."

Success measure: more correct, complete deliverables per fixed task budget, not merely more completed conversations.
