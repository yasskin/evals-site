Methods and limits

How the test was run and graded, and what it can and cannot tell you. For definitions, see the glossary.

What ran

TasksAll 220 public GDPval gold tasks: 44 occupations, five tasks each. See the tasks.
OpenAI modelGPT-6 Astra (gpt-6-astra) with a low reasoning setting, through OpenAI's API
Anthropic modelClaude Opus 5.5 (databricks-claude-opus-5-5) with default settings, through Databricks
AttemptsOne fresh try per task per model (440 in total). All GPT tasks ran first, then all Claude tasks.
ToolsBoth models could run Python code, search the web and work with images. They received the same input files and instructions.
Limits14 turns, 24 tool calls, 10,000 tokens per reply and 50,000 tokens written per task

How it was graded

  • Each model acted as a judge and graded both models' files against each task's original checklist, including point deductions for serious errors.
  • Judges were not told which model made a file (blinded), though writing style or file names could still give hints.
  • For each checklist item, the judge answered pass, fail or unverified (could not tell). Our code then added up the points.
  • Unverified items turn each score into a range. If two models' ranges overlap on a task, we call it unresolved rather than guess.
  • The two judges' results are always shown separately, never averaged. Technical failures are not scored as zero.

880 grading jobs = 440 files or attempts × 2 judges. "Valid" means the judge returned a complete, well-formed grade.

Limitations: what this study can't tell you

  • Not an equal-effort match: GPT used a low reasoning setting and Claude used its defaults, so neither was necessarily at its best or at equal cost.
  • One try each: a second run could turn out differently, and we cannot measure how much results vary.
  • Different times: GPT ran before Claude, so web search results may have differed.
  • AI grading: no human experts have checked the grades yet, and judges could not verify 24.3% of checklist items.
  • What judges couldn't inspect: they did not render Office files, recalculate spreadsheets, check citations live, listen to audio or run video/CAD files.
  • Small samples per job: five tasks per occupation are too few to say which jobs a model is good at.
  • Cost: the main runs generated 68.6 million tokens; grading, retries and pilots are extra. Dollar cost has not been totaled.
  • Security: model code ran locally with best-effort restrictions, not in a fully locked-down sandbox.
